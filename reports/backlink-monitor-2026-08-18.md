# Backlink Monitor: 2026-08-18

**Status:** dormant

No Bing Webmaster API key is configured, so no backlink data was fetched.

To turn this on, create a free Bing Webmaster Tools account, verify titansabroad.org, and generate an API key under Settings, API access. Set it as a `BING_WEBMASTER_API_KEY` secret on the repository. The monitor then reports new and lost backlinks to the site each night. It covers our own inbound links only; competitor backlinks need a paid provider and are out of scope here.
