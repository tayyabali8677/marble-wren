## The website ru.nl is temporarily offline

On 21 October, critical vulnerabilities in PHP were disclosed. Security authorities worldwide are advising that websites should be taken offline temporarily. As a precaution, the Radboud University website is also temporarily offline.

The security updates are now available, but still need to be deployed on our systems. It is currently unclear how long this deployment process will take. While this process is taking place, our website and a few other applications will remain unavailable.
